# WordPress（SWELL + Gutenberg）への効率的なカラー反映ガイド

3サイトを作り、それぞれにセージ／アクア／ラベンダーの配色を反映する手順です。
**ブロックを1つずつ編集する必要はありません。** 色は数値で一元管理できます。

---

## まず：このサイトの「色」がどこにあるか

SWELLサイトの色は、次の3か所に保存されています。

| レイヤー | 場所 | 例 |
|---|---|---|
| ① テーマの基本色 | 外観 > カスタマイズ > **基本カラー**（DB: theme_mods） | `--color_main` ほか。ヘッダー・ボタン・見出し・フッター等 |
| ② 追加CSS | 外観 > カスタマイズ > **追加CSS**（DB: custom_css） | `--tiara-*` 変数とデザイン調整。本サイト独自の装飾 |
| ③ ブロック内の色 | 各ブロックの色設定（DB: 投稿本文の `style="..."`） | 背景 `#fdfaf6`、見出し文字 `#c19268`、区切り線 など |

①②は変数で一括管理できますが、③だけは本文に直接書き込まれています。
この③を効率的に変える方法が、反映作業のカギになります。

---

## 推奨ワークフロー（最も効率的）

### 手順の全体像
1. **1サイトだけ完成させる**（現在のデザイン＝ベージュ）
2. その**サイトを2回複製**して、合計3サイトにする
3. 複製した2サイトで、**色コードを一括置換**する（①②③すべてが一度に変わる）

➡ 本文を作り直すのは1回だけ。色違いは「置換」で量産できます。

### 1. サイトの複製
以下のいずれかで、完成サイトを丸ごと複製します（本文・カスタマイザー・追加CSSごとコピーされます）。
- 移行プラグイン：**All-in-One WP Migration** / **Duplicator**
- レンタルサーバーの**ステージング／簡単コピー**機能（エックスサーバー等にあります）

### 2. 色コードの一括置換
複製した各サイトで、**色コードを検索置換**します。これだけで ①②③のすべての色が切り替わります。

- **GUIで行う場合（おすすめ・非エンジニア向け）**
  プラグイン **「Better Search Replace」** を使用。
  - 対象テーブル：`wp_posts`（本文）, `wp_options`（カスタマイザー・追加CSS）を選択（迷ったら全テーブル）
  - **必ず「Run as dry run?（ドライラン）」で件数確認 → 問題なければ本実行**
  - 下の置換表の行数（13行）ぶん、1組ずつ置換します

- **WP-CLIが使える場合（最速）**
  ```bash
  # 例：セージグリーンに置換（--dry-run で確認してから外す）
  wp search-replace '#c19268' '#8fa37a' --all-tables --dry-run
  ```

## 代替案：複製せず「追加CSS」で色を一元管理する

サイトを複製せず個別に作る場合や、今後の色調整を楽にしたい場合は、
**追加CSSの先頭の変数ブロックだけ**を差し替える運用がおすすめです。

- 同梱の **`追加CSS_カラー変数.css`** を、各サイトの
  「外観 > カスタマイズ > 追加CSS」に貼り付けます。
- 先頭の `:root{ … }` の**10個の値だけ**を、サイトごとに差し替えます
  （セージ／アクア／ラベンダーの値はファイル内のコメントに記載）。
- これで ①テーマUI（`--color_*` を上書き）と ②独自装飾（`--tiara-*`）が
  まとめて切り替わります。

ただし **③ブロック本文に直接入った色**（背景 `#fdfaf6`・区切り線 `#c19268` 等）は
CSS変数では追従しません。次のどちらかで対応してください。
- **おすすめ**：それらのブロックを「カスタムカラー（hex直接指定）」ではなく
  **カラーパレットの色**で選び直す。SWELLのカラーパレット
  （外観 > カスタマイズ > エディター設定 等）にブランド色を登録しておけば、
  パレット値を変えるだけで全ブロックが追従します。
- もしくは前述の **Better Search Replace で③のhexだけ置換**する。

## チェックリスト（反映後の確認）

- [ ] ヘッダーの帯・ナビ下線・ボタン・見出し下線がメイン色になっている
- [ ] 「ご予約」ボタン、メニュー番号（01/02/03）、料金（¥表記）の色
- [ ] 区切り線（`<hr>`）の色 ← ③ブロック色。置換 or パレット化で対応
- [ ] フッター／フッター直前の濃い背景セクションの色
- [ ] カード（うすい背景）の色
- [ ] 成功・注意・エラー等のアイコン色が**元のまま**であること

## 補足

- 本リポジトリ `_color-variations/01〜03` の各HTMLは、実際の見た目の確認用プレビューです。
  反映前に「どの色がどこに出るか」をブラウザで確認できます。
- どの方式が御社の環境（サーバー・プラグイン可否）に合うか不明な場合は、
  環境を教えていただければ手順を具体化します。
