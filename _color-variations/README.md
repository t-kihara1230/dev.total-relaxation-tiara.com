# カラーバリエーション（サイトリニューアル用）

リラクゼーションサロンの「清潔感」と「癒し」をテーマに、元デザイン（ベージュ／ブラウン系）の
**レイアウトはそのまま**に、ブランドカラーのみを差し替えた3案です。

## プレビュー方法

`_color-variations/index.html` をブラウザで開くと、3案を一覧・比較できます。
各案のリンクから、実際の全8ページ（トップ／店舗紹介／メニュー各種）の配色を確認できます。

## WordPressへの反映

実際の WordPress（SWELL + Gutenberg）サイトへ効率的に反映する手順は
**`wordpress-適用ガイド.md`** を参照してください。
追加CSSで色を一元管理する場合は **`追加CSS_カラー変数.css`** をそのまま貼り付けて使えます。

## 補足

- 元サイトは SWELL テーマ（WordPress）。配色は HTML 内インラインCSSの CSS変数
  （`--color_main` ほか、サイト独自の `--tiara-*`）と一部のハードコード値で定義されています。
  本バリエーションはそれらブランドカラーのみを置換しています。
- 成功（緑）・注意（黄）・エラー（赤）などの**機能的なアイコン色は視認性のため変更していません**。
- 生成は `build.sh` で行っています。色値を調整したい場合はこのスクリプトの該当パレットを編集し、
  `bash _color-variations/build.sh` を再実行してください。
- 各案フォルダ内の**8ページ間のナビゲーションリンクはフォルダ内の相対パスに書き換え済み**です。
  そのため、トップから「メニュー」「店舗紹介」等をクリックすると、同じ配色のページ同士を
  そのまま回遊できます（`_fix_links.py` が `build.sh` から自動実行されます）。
- 画像・外部CSS・予約/アクセス等のローカルに無いページへのリンクは本番URL（絶対パス）のままです。
